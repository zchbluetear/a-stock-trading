# 板块强势股

入口：导航「板块强势股」，路径 `/market-movers`；API：`GET /api/market/movers`。

- 扫描东方财富沪深 A 股列表（主板、创业板、科创板；不含 B 股、北交所），校验全部分页数量及股票代码唯一性。
- 页面提供“涨停股票”和“涨幅 ≥5%”筛选，默认显示涨停股票；手机竖屏使用板块下拉选择和股票卡片，桌面使用分组列表和表格。
- 行业使用 `f100`，概念使用 `f103`。概念允许一股多组；全部股票及顶部计数按代码去重。板块列表仅展示当前筛选有结果的板块。
- 涨幅采用行情源 `f3 >= 5`，包含其中的涨停股。涨停比较最新价与单股接口实际涨停价 `f51`，不按固定涨幅猜测。正涨幅 ST 股也会核验，覆盖价格舍入后低于 5% 的涨停。
- 涨停价按行情日期缓存；缺失、不匹配或无涨跌幅限制时显示待确认，不虚构涨停身份。无有效最新价、涨幅或时间的股票不参与筛选，页面展示数量。
- 每个后端进程共享一个扫描线程。页面每 60 秒读取结果，扫描按 60 秒周期执行；耗时超出周期时串行完成，不堆积。首次扫描返回加载状态，不阻塞 HTTP 请求。
- 所有访问者停止读取超过 75 秒后，后台扫描退出。暂停按钮停止该页面轮询；其他访问者仍可维持扫描。
- 任何分页失败、重复或数量变化均保留前次完整快照并提示失败。页面显示获取时间和扫描耗时；非当日行情明确提示历史日期。
- 实时程度受公开行情源延迟和限流影响；扫描结果不是交易所同步快照。多进程部署时每个进程各自扫描，需要统一采集时应使用单独行情进程/共享缓存。

正常启动项目后端与前端即可。开发环境若直连行情源不可用，可在后端设置 `MARKET_HTTP_PROXY`（例如本机代理 URL）；不写入全局代理配置。
